# Avaliação 1 (AV1) — Machine Learning 1

Este repositório contém a solução desenvolvida para a **AV1** da disciplina de **Machine Learning 1**, implementada utilizando a linguagem  **Delta**.

---

## Sobre o Projeto

O objetivo desta atividade é resolver os problemas propostos no enunciado da AV1, garantinndo compreensão da discplina além de desenvolver um contato com o **Delta**, linguagem de programação dedicada a criação de documentos dinâmicos. O repositório contém a implementação das 5 questões da AV1 e uma página principal (`index`), organizadas e renderizadas em páginas HTML para visualização.
